#Student Performance Analysis

#Project Overview
This project analyzes student performance data to identify factor that may affect academic performance.

#Tools and Technologies
-Python
-Pandas
-Matplotlib
-SQL/MySql
-Excel
-Power BI

#Dataset
The database contain 1000 students record with information about gender, parental education, lunch, test preparation and math, reading and writing scores.

##Analysis Performs
-Gender wise scores analysis 
-Test Preparation course analysis
-Parental education analysis
-Lunch wise education analysis
-Top performing student analysis
-Data visualization using chart and Power BI.

##Key Objectives
To understand student performance pattern and presence useful insights through data analysis and visualization.
